# Scoreler CLI — 1.4

可选终端组件随 Scoreler 1.4 提供。

在 Scoreler 设置中点击「安装 CLI」，然后从开始菜单打开新的 PowerShell 或终端，输入：

```powershell
scoreler
```

CLI 从应用附带组件安装，无需重复配置模型；需要时会启动 Scoreler。左侧为对话，右侧显示当天日程。窗口较窄时使用 `/today` 查看完整日程，PgUp/PgDn 滚动聊天。模型选择、日程、历史和助手工具与桌面版共用。CLI 在每次启动时跟随 Scoreler 选中的更新版本，应用更新后请重新打开终端。

常用命令：

| 命令 | 用途 |
| --- | --- |
| `/new` | 新建并保存对话 |
| `/model`、`/model 2` | 列出模型、选择第 2 个模型 |
| `/reasoning`、`/reasoning high` | 查看或选择受支持的推理强度；`default` 恢复默认 |
| `/image "C:\path\题目.png"` | 添加图片；支持 PNG、JPEG、WebP 和 GIF，单张不超过 10 MB |
| `/file "C:\path\材料.pdf"` | 导入并附加学习文件，单个不超过 15 MB |
| `/detach` | 清除待发送附件 |
| `/instructions 先给提示` | 为当前对话的后续消息设置要求；不带文字则清除 |
| `/sessions`、`/resume id` | 列出并继续保存的对话 |
| `/today` | 刷新并查看今日日程 |
| `/answer 回答` | 回答助手的提问 |
| `/allow`、`/deny` | 对当前工具许可选择仅允许本次或拒绝 |
| `/stop`、`/exit`、`/help` | 停止回复、退出、查看帮助 |

支持中文输入。Ctrl+V 可在本机剪贴板支持时粘贴截图，否则粘贴文字；也可始终使用 `/image` 输入图片路径。Windows 终端可能只显示附件提示，模型仍可收到图片。图片识别与工具操作取决于模型能力。每条消息最多 5 张图片（合计不超过 15 MB）和 8 个学习文件，支持 PDF、DOCX、XLSX、PPTX、Markdown、文本、CSV 和 JSON。

CLI 使用带有每次启动随机认证的本地管道连接桌面主进程，不接收服务商 API 密钥或 ChatGPT 访问/刷新令牌。ChatGPT 登录、账号、代理、订阅额度、许可偏好和断开连接仍在桌面设置中管理；发送消息只授权本次对话及其工具后续请求，不新增后台授权。云端模型会接收本次请求所需的指令、对话、图片、资料片段与工具结果。

CLI 当前依赖桌面主程序。绘图笔记、视频等富媒体结果可在应用中查看。移除终端命令会删除它自己的启动文件与用户 PATH 条目，学习记录保留。

本功能复用 [Pi](https://github.com/earendil-works/pi) 的 `@earendil-works/pi-coding-agent`、`pi-ai` 与 `pi-tui`（MIT），使用其编辑器、Markdown 渲染、剪贴板、中文宽度处理和全屏终端基础设施。Scoreler 提供本地连接、启动器、日历布局、命令与设置集成，许可见[第三方声明](../THIRD_PARTY_NOTICES.md)。

## 预览快捷键

- 将鼠标放在日程栏上滚动，或按 Alt+↑/↓，可独立滚动今日日程；日期标题保持可见。
- Alt+V 将剪贴板截图保存到本地并在输入框插入带引号的路径，也支持复制的图片文件路径。发送时只附加输入中仍保留路径的图片；删除路径即可取消该图片。本地路径会从发送给模型的文本中移除。退出 CLI 时清理临时截图，原图片文件不会删除。
